# mzmzeee/tap

Homebrew formulae for [a-stack](https://github.com/mzmzeee/a-stack).

```sh
brew install mzmzeee/tap/a-stack
```

Works on macOS 13 or later and Linux, on amd64 and arm64. To keep a-stack running, run `a-stack service install` after installing, and again after each `brew upgrade`.

The formula is kept in [a-stack's contrib folder](https://github.com/mzmzeee/a-stack/tree/main/contrib/homebrew) and copied here for each release.
